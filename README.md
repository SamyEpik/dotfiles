# dotfiles

Dotfiles for my Arch Linux Hyprland rice

## System

- OS: Arch Linux x86_64
- Shell: zsh 5.9
- WM: Hyprland (Lua config)
- Bar: Quickshell
- Terminal: kitty
- Login: hyprlogin (greetd)

## Key Features

- Sleek and productive design
- Modern and focused look
- Pywal-based dynamic theming
- Wofi-based system menu
- Touchscreen and touchpad gestures

## Getting Started

- Install everything with [INSTALL.md](INSTALL.md)
- Keep the `.dotfiles` directory as `$HOME/.dotfiles`
- Try _SUPER + A_ to open the system menu
- Learn about this rice in the system menus help section
